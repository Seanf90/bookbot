# BookBot

A Python text analysis tool built as part of the [boot.dev](https://www.boot.dev) curriculum.

## What it does
Reads a plain-text book file and generates a report showing:
- Total word count
- Frequency of every alphabetical character, sorted highest to lowest

## What I learned
- File I/O in Python
- Dictionary manipulation and sorting
- Writing clean, modular functions
- Version control workflow with Git

## How to run
```bash
git clone https://github.com/Seanf90/bookbot
cd bookbot
python main.py
```

Input books go in the `books/` folder. The default uses `frankenstein.txt`.
